# KiCad Plugins

## Gerber2PNG Local

Windows installer for the modified Gerber2PNG KiCad PCB Editor plugin and its local conversion service. The installer bundles its own Python runtime.

[Download the Gerber2PNG Local v1.1.3 installer ZIP](https://github.com/bakstaaj/KiCAD-Plugins/releases/download/v1.1.3/Gerber2PNG-Local-v1.1.3-Windows.zip)

See [Gerber2PNG-Local/README.md](Gerber2PNG-Local/README.md) for installation instructions and source layout.
